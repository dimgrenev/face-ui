# Component Map

## Primitives
- `Button`
- `Text`
- `Icon`
- `Separator`

## Overlay Surfaces
- `Tooltip`
- `Popover`
- `Menu`
- `Modal`
- `Command`

## Navigation
- `Tabs`
- `Accordion`
- `Breadcrumb`
- `Pagination`
- `Steps`
- `Navigation`
- `Panel`
- `Tree`
- `Toc`

## Forms
- `Input`
- `Checkbox`
- `Radio`
- `Switcher`
- `SegmentedControl`
- `Slider`
- `Rating`
- `Select`
- `Date`
- `Calendar`

## Feedback and Measurements

- `Progress` — task completion, including unknown duration
- `Meter` — a known measurement such as quota or storage usage

## Patterns
- `Table`
- `Carousel`
- `Upload`

## Compatibility Only
- `Overlay` -> use `Tooltip` or `Popover`
- `Toggle` -> use `SegmentedControl`
- `Sidebar` -> use `Panel`
