# Button и ButtonGroup

Назначение Button — нативное действие. ButtonGroup объединяет связанные действия, сохраняя их отдельные границы, фокус и native button behavior. Новые ширины/высоты/размеры не добавлены: общая control geometry остаётся единственным основанием размеров.

| Проп | Сценарий и решение | Проверяемый эффект |
| --- | --- | --- |
| `text` | Сохранён для простого редактируемого текста действия в декларативном документе. | Строка появляется и обновляется; rich children имеют явно описанный приоритет. Unit `text, children and rightText…`. |
| `children` | Сохранён для React-композиции подписи: выделенный фрагмент, i18n-компонент, динамический контент. Это содержимое label, а не замена всей кнопки. | React-узлы и число 0 не теряются; удаление children возвращает text. Иконка/secondary slot сохраняются. Наличие двух способов задания label оправдано двумя режимами authoring; дополнительный label/caption prop не добавлен. |
| `rightText` | Сохранён: клавиатурная команда, тариф или краткая метаинформация рядом с действием. | Отдельный слот не растягивается и не исчезает при смене props. Исправлен contrast: убран opacity, дававший 3,66:1 на hover. Browser проверяет оба theme и все варианты. |
| `variant` | Сохранены семь вариантов: обычный, основное действие, второстепенное, акцентное, контурное, малозаметное, разрушительное. | Сравниваются реальные normal+hover paint states: семь различных комбинаций, стабильная геометрия, читаемый текст. Одного data-variant для доказательства недостаточно. |
| `icon` | Сохранён как самостоятельный визуальный слот перед/после подписи: registry name или пользовательский ReactNode. | Реальный SVG/узел в DOM; смена содержимого и относительного положения. |
| `iconPosition` | Сохранён: направление чтения подписи и завершающая иконка действия. | Больше не игнорируется при наличии индикатора; browser сравнивает координаты label/icon/chevron. В iconOnly нет подписи, относительно которой нужно менять порядок. |
| `iconOnly` | Сохранён: компактное действие с полной подписью для assistive technology. | Исправлено исчезновение accessible name. Визуальная подпись скрыта стандартным clipping, не display:none. Компактный режим квадратный; fullWidth и chevron сохраняют свои эффекты. |
| `disabled` | Сохранён: действие недоступно. | Native disabled блокирует активацию и клики по мембране; включение возвращает действие. |
| `loading` | Сохранён: действие выполняется; требуется spinner и busy announcement. Не синоним disabled. | Видимый spinner, aria-busy, заблокированная повторная активация; label и геометрия сохраняются. |
| `stretchText` | Сохранён: распределение свободного пространства внутри кнопки фиксированной/полной ширины. | Измеряется увеличение ширины text slot и положение вторичного текста/иконки. Исправлено игнорирование в боковом disclosure. У intrinsic-width кнопки свободного пространства нет. |
| `fullWidth` | Сохранён: кнопка заполняет доступную ширину родителя. | Проверяется фактическая ширина с membrane и без неё, включая iconOnly/loading. Это ширина внешнего контрола, а не распределение его text slot. |
| `align` | Сохранён: выравнивание содержимого внутри доступной ширины. | left/center/right работают вместе с обеими ориентациями chevron и stretchText. |
| `level` | Сохранён: вложенные action rows в дереве и панели. | Реальный padding растёт с уровнем. Значение ограничено целыми 0…9; дробная часть отбрасывается, удаление возвращает исходную геометрию. |
| `membrane` | Сохранён: внешняя граница попадания/расстояния, когда её не задаёт родительская композиция. | Одно действие при клике по padding, стабильная native button identity, отсутствие внешнего отступа при false. Прозрачная обёртка сохраняется, чтобы переключение не пересоздавало кнопку. |
| `chevron` | Новый единый параметр down/right заменяет selector+selectorDirection. Название описывает видимый элемент, не вводит новую разновидность кнопки. | Индикатор остаётся последним, не переставляет icon и не отменяет align/stretchText. |
| `aria-expanded` | Единственный источник раскрытого состояния; стандартное имя вместо selectorOpen. | AT state и направление chevron согласованы. Boolean и native Booleanish поддержаны; при отсутствии chevron атрибут сохраняет обычный смысл. |
| `selector`, `selectorDirection`, `selectorOpen` | Удалены: два параметра управляли одним индикатором, третий повторял native ARIA state и не работал для бокового индикатора. | Отрицательные TypeScript cases, AST migration и реальные потребители. |
| `copyText` | Сохранён: готовая повторяемая операция копирования, включая пустую строку. | Keyboard/padding click вызывают clipboard; отменённый onClick останавливает copy. Ошибка не сообщает об успехе. |
| `onCopied` | Сохранён как результат успешной async операции, а не дубликат onClick. | Ровно один callback после успеха, отсутствие при ошибке/отмене; новые props используются следующими действиями. Удалён бесполезный internal copied state/timer без визуального эффекта. |
| Native props, `className`, `style`, `ref` | Адресуют фактический button, а не membrane. Native type/form/name/value нужны для действий форм. | Unit проверяет маршрутизацию; browser проверяет submit/validation/reset, Enter/Space, copy и disabled. Ref передаётся напрямую: устранена потеря callback cleanup React 19. Недействующие input defaults и опасная замена внутреннего DOM исключены из типа. Полный общий аудит наследуемых props продолжается. |

ButtonGroup: `children` — набор действий, `orientation` — горизонтальная/вертикальная ось, `className` и native attributes — адресация и accessible name группы. Добавлена полноценная типизация root attributes. Исправлены правила внутренних углов для стандартных Button с membrane; проверяются координаты реальных кнопок, а не только data-orientation.

## Проверки

- `assets/__tests__/props-button.test.tsx`: содержание, состояние, clipboard, native props и React 19 ref cleanup.
- `scripts/browser/props-button.spec.ts`: обе темы, все варианты, измерения ширин/координат/indent, clipping label, контраст, native формы и активация. После исправления контраста первоначальные 7 сценариев прошли 42/42 (2 повтора × 3 browser engines). Расширенный набор обнаружил overflow iconOnly+chevron: удалено дублирующее ограничение геометрии из base.css, размером теперь владеет компонент. Все 8 сценариев прошли в трёх браузерах на React 18 и React 19 в составе полной матрицы 240/240 на каждой версии.
- `assets/__tests__/button-migration.test.ts`: dry run, aliases, conditional props, приоритет существующего aria-expanded, неприкосновенность Tile и идемпотентность.
- `assets/__tests__/props-types.tsx`: допустимый новый API и отклонение удалённых параметров.

Скрипт миграции обработал Panel/Tree и реальные Button usages приложения. Tile.selector пока остаётся отдельной незавершённой частью аудита, а не считается автоматически проверенным вслед за Button.
