# Avatar

Назначение: компактная идентификация человека или участника в списке, комментарии, карточке автора. Это пассивное изображение; кнопка профиля собирается родителем. Размер принадлежит общей control geometry, произвольный size не добавлен.

| Проп | Сценарий и решение | Наблюдаемый контракт и проверка |
| --- | --- | --- |
| `src` | Сохранён: фотография участника; общепринятое имя native image source. | Реальная загрузка, ошибка, пустой URL, замена во время loading/loaded/error. Старый запрос не меняет новый аватар. Unit `src follows actual image events…`; browser `Avatar src and fallbackDelayMs…`. |
| `name` | Сохранён: полное имя задаёт осмысленные initials и доступное имя. | Изменение имени обновляет initials и accessible name независимо от состояния изображения. Пробелы нормализуются. Unit `name updates initials…`; browser проверяет имя до и после загрузки. |
| `fallback` | Сохранён как единственный пользовательский слот вместо initials: знак неизвестного пользователя, иконка бота, инициалы особого формата. | Строка, число 0, React-иконка, удаление после mount; резервный контент виден только при отсутствии изображения. Unit `fallback replaces initials…`, browser проверяет реальную видимость и центрирование иконки. |
| `icon` | Удалён: полностью дублировал `fallback={<Icon />}` и вводил скрытый приоритет между тремя входами. | Отрицательная TypeScript-проверка. Миграция ниже. |
| `children` | Удалён: был ещё одним синонимом custom fallback, а не отдельной композицией. | Отрицательная TypeScript-проверка; всё резервное содержимое имеет одного владельца. |
| `fallbackDelayMs` | Сохранён: короткая задержка предотвращает вспышку initials при быстрой загрузке фото. Имя явно определяет назначение и единицу. | Задержка действует только на pending image; ошибка/отсутствие src показывают fallback сразу. Изменение задержки во время loading начинает новый отсчёт. Отрицательные, NaN и Infinity означают 0. Unit с fake timers + реальная задержка в трёх браузерах. |
| `className` | Сохранён как стандартная интеграция с оформлением продукта. | Класс применяется к тому же span, что ref/role/ARIA; browser проверяет сохранение геометрии. |
| HTML/ARIA, `style`, events, `ref` | Добавлена обычная адресация корневого span: описание/связь с именем рядом, декоративный аватар, оформление, DOM-интеграция. | Unit проверяет id/title/style/click/ref/aria-label; browser — цвет и исключение декоративного изображения из accessibility tree. Входы `children`, `dangerouslySetInnerHTML`, `defaultChecked`, `defaultValue` исключены: Avatar владеет внутренней разметкой и не является полем ввода. Полная общая проверка наследуемых атрибутов остаётся в плане аудита. |

Не добавлялись `alt` и отдельный `decorative`: они повторили бы стандартные `aria-label`/`aria-labelledby` и `aria-hidden` на стабильном корне. Внутренний img имеет пустой alt, чтобы полное имя объявлялось один раз как для фотографии, так и для fallback. Пользовательский fallback должен быть пассивным; интерактивное действие принадлежит внешней кнопке.

## Исправленная реализация

Убрана параллельная загрузка через `new Image()`: состояние следует load/error реального img. Source change сбрасывает цикл в том числе из loading. Нативный img всегда сразу получает актуальный src: браузерная регрессия обнаружила в Firefox гонку, когда новый DOM-узел успевал загрузить предыдущий src до синхронизации машины. Таймер имеет явный cleanup и контролируемый повторный вход состояния.

## Миграция

```tsx
// Было
<Avatar name="Research assistant" icon="component" />
<Avatar name="Ada Lovelace">AL</Avatar>
// Стало
<Avatar name="Research assistant" fallback={<Icon name="component" />} />
<Avatar name="Ada Lovelace" fallback="AL" />
```

Если раньше одновременно были children/icon/fallback, переносится фактически видимый контент: прежний приоритет был children → icon → fallback → initials. Другие входы удаляются. JSON-сценарии и галерея обновляются генераторами.

## Доказательства и незавершённые проверки

До исправления: 6/8 новых unit cases падали. После исправления: все 8 проходят. Browser: 2 сценария × Chromium/Firefox/WebKit × 3 повторения = 18/18 после устранения гонки Firefox. Явный reentry runtime проверен отдельно на порядок cleanup/exit/entry и отсутствие перезапуска обычного self transition. Последующие проверки React 19, полных матриц и потребителей записаны в README этого каталога. Unicode initials дополнительно исправлены и проверены в [Unicode-direction.md](Unicode-direction.md): surrogate pairs, combining marks, ZWJ/skin tone/flags, Indic conjuncts и SSR. Завершение всей библиотеки и всех платформенных сочетаний здесь не заявляется.
