# Badge

Badge — статическая inline-метка состояния или счётчик. Собственный onValueChange, selectable, loading, disabled или автоматический live region не добавлены: они не следуют из назначения компонента. Динамические объявления можно задать нативным role/aria-live в конкретном сценарии.

| Проп | Решение и сценарий | Проверка |
| --- | --- | --- |
| `text` | Сохранён: редактируемое короткое состояние/значение в декларативной модели. | Видимая строка и её замена. |
| `children` | Сохранён: составная inline-подпись, иконка состояния, форматированный счётчик. Приоритет над text совпадает с Button/Text. | Rich node, 0, false, пустая строка, null и возврат к text; устранён унаследованный пустой слот Text. |
| `appearance` | Сохранён: fill для выраженной метки, outline для спокойного контекста. Независим от смысла статуса. | Обе формы × пять тонов × светлая/тёмная темы, фактические фон/цвет/обводка и axe contrast. |
| `tone` | Сохранены neutral/accent/positive/warning/destructive: нейтральная метаинформация, акцент, успех, предупреждение, ошибка. | У каждого тона отдельный semantic token. В авторской монохромной светлой палитре accent и destructive совпадают; это не независимые оттенки по умолчанию. Тестовая цветная палитра подтверждает независимую смену каждого тона для fill и outline. Смысл должен сообщать текст, а не один цвет. |
| Native span props, `className`, `style`, events, `ref` | Сохранены на самом Badge; ref не указывает на Membrane. Удалены неработающие input defaults и dangerouslySetInnerHTML, конфликтующий с принадлежащим Text DOM. | Проверяются role/ARIA/name, id/title, язык/направление, видимый стиль, callback и ref. |

Badge использует Text и общую Membrane, не реализует ещё один способ внешних отступов. Отдельный membrane prop не добавлен без доказанного сценария вложения Badge в границу с такими же отступами; существующие настройки Text не объявляются автоматически частью API Badge.

Регрессии: `props-text-badge-icon.test.tsx`, `props-text-badge.spec.ts`, `props-types.tsx`. Полные React 18/19 и потребительские проверки этой партии прошли; числа и ограничения указаны в README этого каталога.
