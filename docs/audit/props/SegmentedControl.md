# SegmentedControl / Toggle — индивидуальный аудит

Контрольная точка завершена 17 сентября 2026. Общий аудит библиотеки продолжается.
Источник — canonical Face UI; app/site/Defrictor получают
генерируемые снимки. Текущая интеграция включает семь прямых потребителей в Desktop
settings (General, Appearance, Hooks, Mcp), собранный пакет и реальные примеры
галереи. Первоначальный список потребителей оказался неполным: ошибки app typecheck
выявили оставшийся старый формат массива. Все семь переведены на scalar single API.
Прямой SegmentedControl в Setting получает видимую подпись и описание строки;
составные поля Hooks/MCP имеют собственные native имена.
Спецификация и журнал: `.artifacts/segmented-spec.md`,
`.artifacts/segmented-integration.md`. Tabs ещё не проходил эту проверку.

## Концепция и решения

SegmentedControl — компактный набор видимых вариантов. Один вариант имеет
семантику radio; несколько независимых — pressed buttons. Radio не снимает
выбор повторным нажатием. Это соответствует выбранным паттернам
[W3C Radio Group](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) и
[W3C Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/), проверенным
13 сентября 2026. Это решение о поведении компонента, не заявление о полной
доступности библиотеки или о проведённом ручном тестировании screen reader.

Одна реализация хранит принятый выбор, обрабатывает события и размещает общую
Membrane. Отдельная toggle FSM с двумя одинаковыми обработчиками удалена.
Toggle — только адаптер устаревшего формата, без копии списка общих props.

| Prop / поле | Сценарий и решение | Наблюдаемый эффект / ограничения |
| --- | --- | --- |
| items | Видимые режимы редактора, каналы уведомлений, набор фильтров. Readonly. | Порядок определяет DOM, клавиатуру и FormData. Отсутствие — пустая группа. Некорректные элементы и повторные ключи вызывают ошибку. |
| item.value | Стабильная идентичность выбора. | Только строка, включая пустую. Не индекс и не результат String(). |
| item.label | Текст/иконка/неинтерактивная композиция. | Содержимое кнопки, перенос длинных подписей. Интерактивные потомки недопустимы. |
| item.disabled | Пункт виден, но недоступен. | Native disabled, исключение из клавиатуры и отправки формы. Существующий выбор остаётся виден. |
| item.id | Связь с внешней разметкой и автоматизацией. | ID самой кнопки. |
| item.aria-label / aria-labelledby | Название иконки или альтернативное доступное имя. | Native имя конкретной кнопки. Не отдельный label alias. |
| item.aria-describedby | Дополнительное объяснение отдельного варианта. | Native связь на кнопке. |
| item.title | Дополнительная native подсказка. | title кнопки; не замена доступного имени. |
| multiple | Один режим или независимые фильтры. | Вместо selectionMode, как в Select. False: string/null и radio; true: readonly string[] и aria-pressed. |
| value | Управляемое состояние в редакторе. | Родитель определяет принятый выбор. Отказ не меняет DOM/FormData. При снятии контроля сохраняется последний принятый выбор. |
| defaultValue | Локальный выбор без внешнего store. | Копия при mount; поздние изменения не сбрасывают ввод. Form reset восстанавливает исходное значение среди текущих items. |
| onValueChange | Предложение пользовательского изменения. | Один callback, независимый массив. Внешние обновления, reset и повторный single выбор молчат. Multiple нормализуется в порядке items. |
| disabled | Временно недоступный редактор настройки. | Все кнопки disabled, форма ничего не отправляет. Native fieldset тоже работает. Opacity применяется один раз. |
| orientation | Вертикальный список режимов в узкой панели. | Реальный flex column/row. Single использует обе пары стрелок; multiple — стрелки своей оси. Горизонталь учитывает фактический CSS direction. |
| membrane | Переключение общей внешней геометрии. | Общая Membrane владеет padding и forwarding. Переключение сохраняет кнопки, state и focus. Компонент задаёт только раскладку и минимальное место под цель. |
| name | Сохранение настройки через native form, без ручных hidden inputs. | Single — одна запись, multiple — повторяющиеся ключи. Null — нет записи, пустая строка — настоящий выбор. Отключённые варианты исключены. |
| form | Панель редактора вне DOM формы. | Внешний form по ID владеет отправкой и reset. |
| autoFocus | Первоначальный вход в открытую панель. | Один раз: выбранный доступный или первый доступный вариант. Позднее true не перехватывает focus. |
| aria-label / aria-labelledby | Название всей настройки. | Native имя группы; ariaLabel удалён. Приоритет имени определяет платформа. |
| aria-describedby / lang / dir / id / title / data-* | Встраивание в корпоративную форму, локализация и automation. | На корневом div. ref тоже указывает на него, поддерживает React19 cleanup. |
| className / style | Размеры контейнера и локальное оформление. | Native root. style.width/inlineSize достаточно: отдельный fullWidth не добавлен. |
| native events | Делегирование, аналитика, отмена действий. | Сначала обработчик потребителя, затем внутренняя команда; preventDefault в capture/bubble учитывается. Навигация single активирует тот же native click. |

Не добавлены required/readOnly: первый требует отдельного контракта валидации,
второй не соответствует редактируемому strip. Для обязательного выбора есть
Radio/Select; для пассивного представления — обычный текст/Badge. Role, checked,
pressed, orientation ARIA, children и dangerouslySetInnerHTML принадлежат компоненту.

Неизвестные выбранные ключи не создают невидимых пунктов. Повторы multiple удаляются.
Удалённый uncontrolled выбор не возвращается после восстановления items; controlled
выбор снова виден, когда его ключ возвращается. При смене multiple → single
остаётся первый выбранный пункт в порядке items. Изменение набора/режима само по
себе не выдаётся за пользовательское событие.

## Toggle и миграция

ToggleProps переиспользует общий native API, items, disabled, orientation, membrane,
name/form/autoFocus. Сохраняются только legacy type (default multiple), массивы
value/defaultValue и callback с массивом. В single допускается не больше одного
значения. Повторный выбор radio теперь сохраняется, как в canonical компоненте.

В новом коде заменить selectionMode="multiple" на multiple, single-массив на
строку/null, ariaLabel на aria-label. Удалены toggleMachine/connectToggle/
toggleAnatomy/ToggleSchema из machine barrel. CSS scope toggle сохранён для
совместимости; мёртвый toggle-group selector и локальное переопределение membrane
padding удалены. Default group border использует токен границы, не толщину membrane.

Генератор контрактов теперь читает authored props через локальные import и
Omit/Pick/Partial/Required/Readonly, сохраняет описания и не копирует native
платформенную поверхность в редактор. Импорт типа не считается доказательством
runtime defaults другой функции. Циклические и отсутствующие imports проверяются.

## Доказательства и границы

До исправлений отдельная диагностика: 12/12 failed. После: 12/12 passed.
Вертикальная раскладка не работала во всех трёх браузерах. После завершения старой
анимации font-weight сдвиг соседних целей подтверждён в Chromium/Firefox/WebKit;
раннее измерение во время transition скрывало дефект. Выбранное состояние теперь
обозначается фоном и границей без изменения размеров текста.

Unit-проверки покрывают владение состоянием, нормализацию, native API, формы,
отмену событий, live focus и compatibility adapter. Реальные browser cases
проверяют ширины/переносы, 24px цели на density16, RTL, обе темы, отдельный selected
border, keyboard, формы, Membrane и contrast/ARIA через axe. Начальные 12
переполнений устранены минимальной шириной места под цель вместе с membrane.

jsdom неверно отправляет disabled option — подтверждено на голом native select.
Его unit-тест проверяет выбранные/disabled options; реальный FormData, включая
null/empty/disabled, проверяется в трёх браузерах. WebKit Tab в fixture требует
явного tabindex у внешних test buttons; это не изменение component navigation.

Текущий `pnpm check` после согласования с Text.heightMode: React18 — 1246 passed
и 11 React19-only skips; React19 — 1257 passed. Сборка, типовые примеры,
контракты, gallery, ESM/CJS smoke и упаковка прошли. Отдельная проверка Text/Badge
в трёх браузерах — 33/33, включая высоту всех вариантов Text.
Полная браузерная матрица React19 текущего исходника — 2152 passed + 8 skips.
React18: последняя полная матрица до добавления heightMode — 2146 passed + 8 skips;
после добавления проверен затронутый Text/Badge набор 33/33. Ранее финальная
Segmented/quality матрица — 164 passed + 1 WebKit forced-colors skip.

Собранные app/site consumers: 262 passed + 2 WebKit forced-colors skips. Реальные
Desktop settings с compiled Face: 48/48 в трёх браузерах, обеих темах, на 360/1100px;
18 unit cases настроек и Setting. Подменены только контекст аккаунта/платформы и
сеть, не компоненты UI. Визуально просмотрены восемь узких экранов настроек.

App typecheck и повторный desktop build прошли после миграции семи потребителей;
site build, Defrictor UI check и build отдельной копии прошли. Def build относится
к зафиксированному состоянию: последующие независимые правки контента не входят
в эту проверку. Face snapshots совпадают; manifest и proof-pack прошли.
Общий production-isolation gate сохраняет четыре прежних замечания к путям в
Playground migration.json. Полный журнал и границы — `.artifacts/segmented-integration.md`.

Плоский JSON-контракт хранит неоднородный string/array value как any; связь режима
и значения проверяется TypeScript и runtime. Условная схема редактора в JSON этой
партией не добавляется. Наличие контракта или общее число тестов не означает
завершение полного аудита библиотеки.
