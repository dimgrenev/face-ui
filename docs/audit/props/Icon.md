# Icon

Небольшой renderer реестра, без провайдеров и обходных внешних источников. Размер стандартного glyph box — 20×20; нестандартный размер не возвращается как ещё один неработающий size prop.

| Проп | Решение и сценарий | Проверка |
| --- | --- | --- |
| `name` | Обязательное стандартное имя или строка из декларативного источника. Unknown → notdef; пробельное имя → отсутствие иконки. | Отрисован каждый элемент ICON_NAMES; замены имени, trim, неизвестные имена/URL и ключи прототипа. Исправлен поиск constructor/toString/__proto__ как существующих glyph: используется проверка собственных ключей. |
| `className` | Сохранён для цвета, позиции и анимации в конкретном интерфейсе. | Класс достигает SVG, стандартный uf-icon сохраняется. |
| `style` | Сохранён для цвета, прозрачности, transform. Width/height исключены из типа: фиксированная геометрия не должна обещать неработающую настройку. | Проверяются inline paint styles, квадратный box и сохранение собственного viewBox у узкой иконки. Отрицательный type case отклоняет width. CSS overrides/переменные остаются возможностями CSS, а не обещанием произвольного размера API. |
| `label` | Сохранён для доступного имени без видимого текста/hover hint. Не добавлен второй aria-label поверх него: SVG runtime намеренно имеет небольшой явный API. | Декоративное состояние без имени, role=img и aria-label с именем, trim пустого значения, удаление после mount. |
| `title` | Сохранён: SVG title даёт нативную подсказку и имя. При наличии label доступное имя задаёт label, title остаётся подсказкой. | Исправлен title-only: раньше SVG оставался aria-hidden. Проверяются совместное использование и удаление/пустые значения. |

Из реализации убраны промежуточные iconEntry/builtinEntry и неиспользуемые nativeSize/nativeWidth/nativeHeight: они ничего не решали после удаления внешних источников. Native SVG event handlers/ref не объявлены частью текущего API; интерактивное действие принадлежит Button/Trigger, декоративный glyph сам не становится control.

Регрессии: `props-text-badge-icon.test.tsx`, `props-types.tsx`, `props-icon.spec.ts`. Accessible name, title-only, реальные размеры, paint styles и удаление после mount проверены в трёх браузерах на React 18/19; результаты полной матрицы указаны в README этого каталога.
