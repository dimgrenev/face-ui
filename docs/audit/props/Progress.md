# Progress и Meter: индивидуальный аудит пропсов

В этой фазе Progress разделён по смыслу использования: выполнение задачи остаётся
Progress, измерение известного состояния получает Meter. Оба компонента используют
одну внутреннюю реализацию чисел, разметки, оформления и стандартную Membrane.

Это следует из реальных потребителей: в приложении отображаются проверка шрифта и
фоновая задача; на сайте — квота файлов и дневное потребление API. Последние два
случая не являются выполнением задачи. Такое различие задают
[WHATWG Progress](https://html.spec.whatwg.org/multipage/form-elements.html#the-progress-element),
[WHATWG Meter](https://html.spec.whatwg.org/multipage/form-elements.html#the-meter-element)
и [ARIA progressbar](https://www.w3.org/TR/wai-aria-1.2/#progressbar).

## Решения по каждому библиотечному параметру

| Параметр | Для чего нужен и что проверяется | Решение |
|---|---|---|
| `value` | Завершённая работа / измеренное значение; внешнее обновление, дробные числа, выход за границы | Сохранён. Конечное число, ограничивается диапазоном. Значение по умолчанию 0 |
| `max` | Общее количество работы / верхняя граница измерения в единицах приложения | Сохранён, по умолчанию 100. Конечный, строго больше нижней границы; ошибку данных не превращает в выдуманный диапазон |
| `min` | Отрицательный или ненулевой диапазон измерения | Только Meter, по умолчанию 0. Progress всегда начинается с 0 |
| `indeterminate` | Продолжительность задачи неизвестна | Только Progress. Не выдаёт числовое `aria-valuenow`, не показывает число и не вызывает formatter. Возврат к известному состоянию использует последнее значение |
| `tone` | Смысл состояния определяется продуктом, а не процентом | Сохранён: neutral / positive / warning / destructive. Проверяются обе формы и обе темы |
| `shape` | Полоса в строке/секции или компактное кольцо | Сохранён: linear / circle. Обе формы используют одну точную долю. Кольцо сохраняет диаметр и прозрачный центр |
| `showValue` | Видимый текст значения возле индикатора | Сохранён, по умолчанию false. Не меняет числовую семантику. Видимый дубль скрыт от повторного чтения скринридером |
| `label` | Видимая неинтерактивная подпись | Сохранён. Ноль и rich text поддерживаются; false/null/пустые строки/пробелы/пустые массивы и фрагменты не создают пустую строку и не ломают запасное имя |
| `ariaLabel` | Дублировал нативное имя, блокировался пустой подписью | Удалён. Использовать `aria-label` или `aria-labelledby` |
| `aria-label` | Имя без видимой подписи или осознанное переименование | Нативное имя. Непустое значение имеет приоритет над `label` |
| `aria-labelledby` | Связь с существующей подписью вне компонента | Нативное имя с высшим приоритетом. Сгенерированные ID подписей уникальны и стабильны при SSR/hydration |
| `formatValue` | Локализация и предметные единицы без отдельных locale/valueLabel/percentage aliases | Добавлен один callback `{ value, min, max, percent } => string`. Получает ограниченное значение. Непустой результат используется видимо и в `aria-valuetext` |
| `aria-valuetext` | Речевая формулировка отличается от видимой | Нативный speech-only override. Для одной общей формулировки использовать formatter |
| `membrane` | Стандартная внешняя геометрия и встраивание в плотный layout | Добавлен, по умолчанию true. Единственный владелец внешнего отступа; переключение сохраняет DOM |
| `className`, `style`, `ref` | Интеграция и измерение семантического корня | Работают на div с ролью, не на вспомогательном wrapper |
| Нативные HTML/ARIA/data и события | id, dir, lang, hidden, description, title, tabIndex, обработчики | Пробрасываются. По умолчанию компонент пассивный, не добавляет остановку Tab |
| role, children, HTML injection, числовые ARIA overrides, input defaults | Могли бы создавать вторую независимую семантику/контент | Исключены из TypeScript API. Роль и числа принадлежат компоненту |

По умолчанию процент округляется вниз: 99.99% не превращается в сообщение о полном
завершении. Компенсируется только машинная погрешность вычисления целого процента.
Числовой ARIA value и визуальная доля сохраняют дробную точность. Formatter может
вывести предметное значение точнее или в других единицах.

## Исправленные дефекты

До изменения отдельный набор из 8 проверок воспроизводил 5 ошибок: false, пустая
строка и пустой массив подавляли доступное имя; `id` и `aria-valuetext` терялись.
Исходный код и повторный результат сохранены в `.artifacts/progress-before/` и
`/tmp/face-ui-progress-before-recovered.log`.

Удалена полностью производная машина Progress: компонент не имел пользовательских
переходов, но содержал неиспользуемые события, callback и подписки. Подтверждённых
внешних потребителей этих source-only экспортов не найдено.

Геометрия обоих компонентов теперь общая: нет минимального ненулевого штриха при
нулевом значении, кольцо не округляет долю и не рисует сплошной диск в центре.
Селекторы собственных классов не стилизуют чужой `data-part` внутри подписи.
Неопределённая полоса движется по логическому направлению, reduced motion оставляет
статичный видимый сегмент. В forced colors используются системные цвета. Neutral использует fg-muted: прежний fg совпадал с destructive в светлой теме. Четыре тона теперь различаются в обеих темах, сохраняя монохромную палитру системы.

## Миграция

```tsx
// Выполнение задачи: количество завершённых файлов.
<Progress
  value={completedFiles}
  max={totalFiles}
  label="Импорт файлов"
  showValue
  formatValue={({ value, max }) => `${value} из ${max}`}
/>

// Измерение текущего состояния: допустим только известный положительный лимит.
{quota && quota.limitBytes > 0 && (
  <Meter value={quota.usedBytes} max={quota.limitBytes} aria-label="Хранилище" />
)}

// Неизвестное время выполнения задачи.
<Progress indeterminate aria-label="Анализ документов" />
```

`ariaLabel` заменить на `aria-label`. Нулевой/неизвестный лимит не подменять 1 или
100: пока диапазон неизвестен, показывать статус загрузки/недоступности или сами
данные без индикатора. Meter не имеет режима неопределённости.

Публичные импорты Progress сохранены. Meter экспортируется из корня, `/Meter` и
`/Meter/Meter`; новый компонент включён в реестр, gallery, контракты и сценарии.
Engine получает список компонентов из реестра, изменения Engine не потребовались.
Функциональные параметры, включая formatValue, остаются React API: JSON playground
по существующему общему правилу не сериализует функции.

Токены `--uf-progress-*` заменены общими `--uf-range-*`; потребителей старых CSS
переменных в коде продуктов не найдено. Геометрия имеет два настраиваемых токена:
`--uf-range-track-height`, `--uf-range-circle-size`. Внутренние вычисления используют
`--uf-range-percent`; цвет — общие track/indicator семантические токены.

Потребители: app FontValidation/ValidationProgress, app BackgroundTaskList; site
ProfileFilesSection и HostedApiDashboard. Все получают доступные имена; сайт
использует Meter. Снимки распространяются только штатной синхронизацией.
