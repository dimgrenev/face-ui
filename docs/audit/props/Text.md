# Text

Проверяется типографика, семантика и композиция, включая использование Text внутри Badge/Tile и в Markdown renderer приложения. Работа над полной библиотекой продолжается; эта запись не закрывает общий аудит.

| Проп | Решение и сценарий | Наблюдаемый эффект и проверка |
| --- | --- | --- |
| `text` | Оставлен: простая редактируемая строка декларативного документа. | Появляется и обновляется; уступает non-null children. Unit проверяет повторный рендер. |
| `children` | Оставлен: inline React-композиция, переводы, выделение фрагментов. Дополнительный label/content не нужен. | Rich node и 0 сохраняются; null возвращает text, false/пустая строка убирают содержание без пустого слота. Не предназначен для блочной разметки внутри span. |
| `variant` | Оставлены body/muted, heading/h1…h6, label/kbd/code/markdown/blockquote. `heading` — компактный заголовок секции; h1…h6 — визуальная иерархия документа. `markdown` задаёт ритм уже разобранного текста, а не парсит Markdown: это явно описано. | Каждый вариант проверен с каждым размером и обеими сторонами иконки. `blockquote` исправлен с div на настоящий blockquote. |
| `size` | Оставлен как явный размер поверх умолчания варианта. | Исправлено игнорирование в heading и label. Browser измеряет монотонное изменение всех пяти размеров для всех 14 вариантов и отсутствие line-height меньше font-size. |
| `as` | Оставлен: семантика определяется контекстом документа независимо от оформления. | Все допустимые теги проверены; добавлен blockquote. `as="span" variant="h1"` не создаёт heading role. |
| `icon` | Оставлен: имя стандартной иконки или готовый узел. ReactNode уже включает string; альтернативного iconName не добавлено. | Проверяется замена, обе стороны, rich node и удаление; false и пустая строка больше не создают пустой слот с gap. |
| `iconPosition` | Согласован как start/end: статус перед подписью или вспомогательная иконка после неё, с учётом направления чтения. См. Unicode-direction.md. | Unit проверяет DOM-порядок; browser проверяет inset-комбинации. Без icon не меняет геометрию по смыслу. |
| `inset` | Оставлен: выравнивание с controls либо встроенный текст без padding. | Исправлен конфликт none с icon, kbd и blockquote. Browser измеряет нулевой padding у всех вариантов с обеими сторонами иконки и ненулевой у control. |
| `heightMode` | Добавлен пользователем: `control` по умолчанию сохраняет прежнюю геометрию; `content` предназначен для заголовков и абзацев по высоте содержимого, сохраняя горизонтальный inset. | Проверяются все варианты на ширинах 240/800px, с иконкой и без, с обоими inset. Найден и исправлен конфликт специфичности label: вертикальные padding 4px перекрывали content. Измеряется высота содержимого, отсутствие вертикальных padding/min-height и неизменность типографики/горизонтальных отступов. |
| `stretchText` | Оставлен: расширение внутреннего текстового слота между иконками. | Browser измеряет увеличение слота при фиксированной доступной ширине. Отличается от fullWidth, который расширяет всю границу. |
| `fullWidth` | Оставлен для строк и подписей на всю доступную ширину. | Browser измеряет ширину с мембраной и без, в сочетании с align/stretchText/truncate. |
| `align` | Оставлен: позиционирование содержимого и выравнивание текста. | Проверяются все три значения с полной шириной и обеими конфигурациями мембраны. |
| `membrane` | Оставлен: ровно одна внешняя граница, возможность встраивания в готовый control. | DOM содержит общую Membrane либо сам Text; native ref адресует текстовый узел. |
| `truncate` | Оставлен для компактных строк с ограничением ширины. | Browser подтверждает scrollWidth > clientWidth, ellipsis и отсутствие выхода за родителя; false возвращает переносы. |
| `htmlFor` | Оставлен стандартный React-атрибут label; применяется только когда выбран label через variant/as. | Реальный browser click фокусирует связанный input. На остальных тегах атрибут не выводится. |
| Native `id`, `title`, `role`, ARIA, `lang`, `dir`, `className`, `style`, events, `ref` | Сохранены на фактическом текстовом элементе. Исключены input-only defaults и dangerouslySetInnerHTML, несовместимый с принадлежащими Text слотами. | Unit проверяет root routing, rich children, callback, стиль и ref. Проверка платформенных атрибутов не является сертификацией всех AT/браузерных сочетаний. |

Исходные проверки обнаружили пустые слоты, неверную семантику, игнорирование размера и конфликт inset. Регрессии: `assets/__tests__/props-text-badge-icon.test.tsx`, `scripts/browser/props-text-badge.spec.ts`, отрицательные типовые примеры в `props-types.tsx`. Итоги повторных матриц записываются в общем журнале после их завершения.
