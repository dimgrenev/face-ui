# Slider: индивидуальный аудит пропсов

Одна модель значения, клавиатуры, указателя, формы и мембраны заменяет независимые
Simple/Advanced реализации и машину. `showValue` меняет только отображение числа.
Crop работает независимо от оформления; на сайте его параметры раньше молча
игнорировались, потому что FontPropsPanel не передавал `variant="advanced"`.

## Воспроизведённые дефекты и решения

До исправлений 16 из 17 диагностических проверок падали: native root props терялись,
rich label перекрывался общим «Slider», формы не получали name, после расширения
bounds возвращались старые значения, точность терялась после 12 значащих цифр,
некорректные массивы частично отфильтровывались, сортировка отображения расходилась
с клавиатурой, смена варианта пересоздавала состояние, отказ принять crop менял
основное значение. Все 17 диагностик затем прошли на новом API.

Реальные потребители: FontPropsPanel app/site — оси шрифта и интервал анимации;
ColorPicker — opacity 0..1; BoundedNumberControl — число вместе с прямым вводом;
TypeRenderCut и Typesetter — размер и оси шрифта. Legacy Feld Slider в Defrictor
является отдельной библиотекой, а не потребителем этого компонента.

## Решения по каждому параметру

| Параметр | Сценарий и поведение |
| --- | --- |
| `value` | Контролируемое число либо readonly непустой массив; единая отсортированная нормализация для интерфейса, действий и формы. Отказ родителя сохраняет принятое значение |
| `defaultValue` | Начальное значение для неконтролируемого поля и reset; по умолчанию min. Изменение default после mount не пересоздаёт состояние |
| `min` | Конечная нижняя граница и начало сетки шагов, по умолчанию 0 |
| `max` | Конечная верхняя граница не меньше min, по умолчанию 100. При сужении неконтролируемое состояние сохраняет нормализованное значение и не воскресает при расширении |
| `step` | Положительный конечный шаг, по умолчанию 1. Decimal integer arithmetic сохраняет дроби и большие смещения; слишком малый, не меняющий Number шаг явно отклоняется |
| `disabled` | Нативно запрещает редактирование и отправку всех рукояток; disabled fieldset действует так же. Прозрачность применяется один раз |
| `orientation` | Horizontal учитывает фактическое направление текста, vertical увеличивается вверх. Меняется геометрия, а не модель состояния |
| `label` | Один видимый noninteractive ReactNode, включая rich text; работает с общей Membrane |
| `aria-label` | Native имя при отсутствии видимой подписи либо её явное переопределение |
| `aria-labelledby` | Имя из внешних элементов; приоритет над label/aria-label |
| `labels` | `thumbs` задаёт полные имена всех основных ползунков по порядку; `cropStart`/`cropEnd` локализуют границы. Общая подпись не дублируется внутри полного имени |
| `showValue` | Число внутри той же рукоятки; переключение сохраняет DOM, фокус и значение. Заменяет variant |
| `formatValue` | Один форматтер для видимого числа и aria-valuetext, с value/index/kind. Полный текст остаётся доступен при визуальном сокращении длинных единиц |
| `onValueChange` | Предложение только пользовательского изменения основных значений. External updates, нормализация, reset и повторное значение молчат |
| `onValueCommit` | Принятое изменение после pointerup, окончания клавиатурного ввода либо native assistive input; отказ родителя и отмена жеста не считаются завершением |
| `crop` | Включает два редактора границ независимо от showValue; отдельная возможность, а не побочный эффект оформления |
| `cropRange` | Принятые контролируемые границы, нормализованные той же сеткой. Предложение не становится принятым автоматически |
| `defaultCropRange` | Начальные неконтролируемые границы для mount/reset, по умолчанию весь диапазон |
| `clampToCrop` | Ограничивает основные значения принятым crop. Значение false нужно реальному сценарию playhead вне интервала анимации. Заменяет двусмысленное cropLocksValue |
| `onCropChange` | Предложение изменения границ отдельной копией данных. Мутация callback payload не меняет внутреннее состояние; пересчёт ограничений не вызывает onValueChange |
| `onCropCommit` | Завершённое принятое редактирование crop, со своей проверкой отмены и отказа |
| `name` | Нативный ключ для основных значений: повторяющиеся записи FormData, в порядке возрастания |
| `cropName` | Отдельный нативный ключ для start/end включённого crop. Не смешивает границы и playhead |
| `form` | Явный внешний владелец нативных inputs и reset |
| `autoFocus` | Первый доступный основной ползунок при mount; обновления не крадут фокус |
| `membrane` | Единственная общая Membrane для каждой рукоятки и подписи; false не пересоздаёт inputs |
| `className`, `style`, native attrs/events | Корневой group получает native атрибуты; отмена pointer/key/capture учитывается. Геометрия использует фактические размеры и direction |
| `ref` | Стабильный корневой div с поддержкой React 19 callback cleanup |

Удалены variant, leadingIcon/leadingText и отдельный SliderAdvanced. Ведущий контент
компонуется через label/соседние элементы. Не добавлены бесполезные для native range
required/readOnly: у диапазона всегда есть значение; пассивное измерение — Meter.
Их ARIA aliases также исключены: они не создают поведения и не применимы к group.
Клавиатурные и ARIA значения принадлежат самому контролу, произвольные children
не могут разрушить его структуру. Исполняемые callbacks/formatValue остаются в
TypeScript API, а не сериализуются в JSON по общему правилу контрактов библиотеки.

## Взаимодействие и визуальное согласование

У каждого thumb стабильная позиция в Tab-порядке и зависимые min/max. Основные
значения не пересекаются. При совпадении значений выбор ближайшего thumb на треке
позволяет раздвинуть диапазон в обе стороны. Crop редактируется в соседнем ряду (вертикально — в соседней колонке).
Смещения только вдоль шкалы не предотвращали пересечение с независимым playhead;
две дорожки сохраняют общую числовую сетку и разделяют области нажатия. Клик
по crop-дорожке меняет ближайшую границу; при `clampToCrop={false}` основной
playhead сохраняется.

Модель клавиатуры и именования сверена с
[APG Slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider/) и
[APG Multi-thumb Slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb/).
Нативные range inputs обеспечивают значение, форму и assistive input; семантика
[HTML range](https://html.spec.whatwg.org/multipage/input.html#range-state-(type=range))
сохраняется и для десятичных шагов. Это не заявление о прослушивании экранным диктором.

Один координатный расчёт обслуживает dot, число, crop, RTL и vertical. Смена размера
контейнера во время drag использует текущую геометрию. Pointer id/capture, потеря
захвата, отмена, disable и unmount не оставляют активных document listeners.
Попадание в мембрану проходит через общую Membrane; отдельного механизма padding
forwarding у Slider нет. Минимальные цели — 24px, в том числе при control height 16.

Визуальная проверка выявила ошибку production lowering `:dir(rtl)` в языковой
селектор: координаты значений проходили, а видимая рукоятка смещалась. Центрирование
заменено на логические inset/margin/border с измеренной шириной обёртки;
теперь проверяется положение самой видимой рукоятки, включая CSS direction.
Длинные форматированные значения ограничены шириной контейнера, используют bdi,
а disabled прозрачность принадлежит всему Slider один раз. Нулевая ширина
обёртки тоже исключена: Firefox пропускал клики по выступавшему padding мембраны.
Размер числовой рукоятки обновляется в том же layout commit, что и её текст:
отложенное измерение после 100→0 оставляло устаревшие края трека и давало 69
при клике в ранее вычисленную точку 70. ResizeObserver следит за внешней геометрией.
